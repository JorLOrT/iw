CSS significa Cascading Style Sheets (Hojas de Estilo en Cascada).

CSS como estándar web

CSS es un estándar web porque es una tecnología definida y regulada por organismos internacionales como el W3C, lo que garantiza que funcione correctamente en todos los navegadores.

Esto significa que los desarrolladores pueden usar CSS para diseñar páginas web sabiendo que su apariencia será consistente en diferentes dispositivos y plataformas.

Con CSS puedes cambiar colores, tamaños, fuentes, márgenes y la forma en que se ve una página web.

¿Para qué sirve?

  • Mejorar la apariencia de una página web
  • Separar el contenido (HTML) del diseño (CSS)
  • Hacer sitios web más atractivos y profesionales

Evolución de CSS (Versiones)

Desde su creación, CSS ha evolucionado en diferentes versiones para adaptarse a las necesidades de la web moderna:

  • CSS1 (1996): La primera versión. Incluía propiedades básicas para fuentes, colores, alineación de texto y márgenes.
  • CSS2 (1998): Introdujo el posicionamiento de elementos (absoluto, relativo, fijo), el índice Z (z-index), soporte para diferentes tipos de medios (pantallas, impresoras) y mayor control general sobre el diseño.
  • CSS3 (1999 - Actualidad): Revolucionó el diseño web al dividirse en "módulos". Trajo características avanzadas como sombras, bordes redondeados, degradados, animaciones, transiciones y potentes sistemas de diseño como Flexbox y CSS Grid. Además, introdujo las Media Queries, las cuales son fundamentales para el diseño responsivo (adaptable a dispositivos móviles).

Ventajas de cumplir con el estándar CSS

  • Accesibilidad: Facilita la lectura del documento a lectores de pantalla y a los motores de búsqueda al tener un HTML más semántico y limpio.
  • Mantenimiento: Al separar el estilo, es mucho más fácil actualizar el diseño de un sitio web completo modificando una sola hoja de estilos.
  • Rendimiento: Reduce la cantidad de código repetido en el HTML, resultando en archivos más livianos y tiempos de carga más rápidos.

CSS más allá de HTML

Aunque CSS se asocia comúnmente con HTML, es un lenguaje independiente de presentación que puede dar estilo a diversos tipos de documentos estructurados. Algunas de las otras tecnologías con las que funciona son:

  • XML: Cualquier documento XML puro puede ser estilizado con CSS para mostrar visualmente su información estructurada.
  • SVG (Gráficos Vectoriales Escalables): CSS es fundamental para dar color, aplicar estilos e incluso animar gráficos vectoriales e ilustraciones en la web.
  • XUL y otras interfaces: Antiguamente usado para las interfaces de Firefox. Hoy en día, muchos frameworks para crear aplicaciones móviles y de escritorio (como React Native, Electron o GTK) adoptan motores basados en CSS para definir su diseño.
  • EPUB: El formato estándar para libros electrónicos utiliza CSS para establecer la tipografía, los márgenes y el diseño de las páginas del libro.

Funciones en CSS

CSS no solo asigna valores estáticos, sino que también incluye funciones integradas que permiten calcular valores dinámicamente, manipular colores o aplicar efectos visuales. Algunas de las más utilizadas son:

  • calc(): Permite realizar operaciones matemáticas simples (sumas, restas, multiplicaciones, divisiones) para determinar el valor de una propiedad. Ejemplo: width: calc(100% - 50px);
  • var(): Se utiliza para llamar y aplicar el valor de una variable CSS personalizada (Custom Properties). Ejemplo: color: var(--color-principal);
  • Funciones de color (rgb, rgba, hsl): Permiten definir colores mediante la mezcla de canales rojo, verde y azul, o por su matiz, saturación y luminosidad. Ejemplo: background-color: rgba(0, 0, 0, 0.5);
  • url(): Sirve para enlazar e importar recursos externos, como imágenes de fondo o fuentes tipográficas. Ejemplo: background-image: url('fondo.jpg');
  • linear-gradient() y radial-gradient(): Generan transiciones de color suaves y personalizables para usar como fondos, sin necesidad de cargar imágenes.
  • Funciones de transformación (translate, rotate, scale): Se usan dentro de la propiedad transform para mover, rotar o cambiar el tamaño de un elemento, muy útiles para animaciones.
